# Пример: вернуться к чтению

**Всё ниже вымышлено для объяснения упражнений. Это не отзыв и не результат участника.**

Исходная ситуация: человек хочет читать учебную книгу, но откладывает начало.

| Практика | Пример записи |
|---|---|
| 1. Цель | Разобраться в одной небольшой главе и объяснить главную мысль |
| 2. Помеха | Не знаю, с какого места продолжать. Проверю, поможет ли заранее выбранный абзац |
| 3. План | После выбранного приёма пищи открою книгу на закладке и прочитаю абзац |
| 4. Попытка | Прочитал два предложения; прервался. Могу пересказать их смысл |
| 5. Проверка совета | ИИ предложил час чтения, но у меня десять минут. Выбрал меньший объём |
| 6. Самостоятельно | Сам выбрал следующий абзац; попросил пояснить только непонятное слово |
| 7. Итог | Короткий подход оказался посильным в этой ситуации. Хочу повторить и проверить устойчивость |

## Что здесь важно

Цель не превратилась в обязанность прочитать всю библиотеку. Неполная попытка записана точно. Совет ИИ сопоставлен с реальными условиями. Следующий шаг выбран человеком.

Этот пример показывает способ заполнения. Он не предсказывает, как пройдёт твой маршрут.
