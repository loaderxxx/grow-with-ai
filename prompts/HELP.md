# Когда разговор с ИИ застрял

Эти запросы предназначены участникам для собственных задач. Выбирай один по ситуации.

## Слишком много советов
```text
Остановись. Оставь один следующий шаг.
Учти мои ограничения: [ограничения].
Если их не хватает, задай один вопрос.
```

## ИИ слишком быстро согласился
```text
Проверь мою идею критически и уважительно.
Назови сильный аргумент против неё.
Отдели факты от предположений.
Скажи, какие сведения могли бы изменить вывод.
```

## Ответ звучит уверенно, но непонятно почему
```text
Какая часть ответа основана на моих словах, какая на внешних источниках,
а какая является предположением?
Для важного внешнего утверждения дай проверяемый источник.
Если источника нет, обозначь неопределённость.
```

## Хочется, чтобы ИИ всё решил за меня
```text
Дай одну подсказку, затем дождись моей попытки.
Не выбирай за меня и не выдавай полный план сразу.
Помоги мне сформулировать собственную причину выбора.
```

## Не получилось выполнить шаг
```text
Я планировал: [план]. Фактически: [факт].
Помоги найти одно изменение условий или уменьшение шага.
Не объясняй неудачу чертами моей личности.
```
