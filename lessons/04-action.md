# Практика 4. Сделать и заметить

**Ориентир:** выбранное тобой действие плюс 3 минуты записи. **Результат:** факт попытки.

## Закрой чат на время действия

Выполни шаг из карточки, когда наступят выбранные условия. Сегодня основная работа происходит в реальности.

## После попытки запиши

| Вопрос | Твой ответ |
|---|---|
| Что я планировал? | |
| Что сделал фактически? | |
| По чему это видно? | |
| Что помогло или помешало? | |
| Что изменю в следующей попытке? | |

Можно использовать [дневник действий](../templates/PRACTICE_LOG.md). Это твои записи; публиковать их не требуется.

## Если хочется разобрать результат

```text
План: [мой шаг].
Факт: [что произошло].
Помоги сравнить план и результат без оценок моей личности.
Не называй выполненным то, чего я не сделал.
Предложи одно небольшое изменение для следующей попытки.
Если данных мало, спроси, а не выдумывай причину.
```

**Вымышленный пример:** запланировал прочитать абзац, прочитал два предложения, затем отвлёк звонок. Запись «два предложения» точнее, чем «всё провалил» или «полностью справился».

## Если не начал

Запиши «не начал» и обстоятельства. Уменьши шаг или измени условия. Можно также решить, что цель сейчас неактуальна.
