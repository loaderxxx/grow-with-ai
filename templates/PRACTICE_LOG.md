# Дневник действий

Сохраняй у себя. Достаточно одной строки после попытки.

| Дата / попытка | План | Факт | След результата | Помеха / помощь | Следующий шаг |
|---|---|---|---|---|---|
| | | | | | |

**Пример — вымышленный:** «Попытка 1 / один абзац / два предложения / могу пересказать их смысл / прервал звонок / повторить в другое выбранное время».

Если удобнее голосом, надиктуй: «Планировал… Сделал… Заметил… Дальше…».
Неизвестные причины помечай как предположения.
